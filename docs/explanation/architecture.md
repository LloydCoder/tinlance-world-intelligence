# Architecture explanation

World Intelligence models changing reality as traceable transformations instead of a mutable current-state store.

```text
Source
  ↓
Raw Artifact
  ↓
Observation
  ↓
Entity / Event / Relationship
  ↓
Temporal World State
  ↓
Change
  ↓
Correlation / Contradiction / Coverage
  ↓
Signal
  ↓
Intelligence
```

| Object | Question |
| --- | --- |
| Source | Where did information originate? |
| Raw artifact | What exact material was acquired? |
| Observation | What was observed or extracted? |
| Entity/Event/Relationship | What structured object does it describe? |
| World state | What state is represented for a time/context? |
| Change | What changed from an earlier state? |
| Signal | Which analytical condition fired? |
| Intelligence | What structured interpretation is exposed to consumers? |

Intermediate representations remain available so intelligence can be traced toward source material. AI-generated output is not promoted to evidence merely because an AI system produced it.

World Monitor is a consumer. TADS and Agent OS consume controlled intelligence interfaces. Agent Platform remains the authority for authorization, approvals, execution, and runtime governance.
