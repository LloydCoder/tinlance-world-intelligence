# Phase 2 — Observation
RAW ARTIFACT -> EXTRACTION CANDIDATE -> NORMALIZATION -> VALIDATION -> OBSERVATION
An observation states what an artifact supports about a subject/predicate/value at an observation time and remains linked to source and artifact. Extraction produces candidates, never authority; validation controls canonical acceptance.
Invariants: exact artifact identity; distinct timezone-aware observed/extraction times; non-inverted valid intervals; deterministic versioned normalization; extraction method/version; attached provenance; observation is not evidence, intelligence, or authority.
