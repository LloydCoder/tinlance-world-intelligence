# Implementation phases

## Phase 0 — Foundation

- repository
- contracts
- ontology
- CI
- documentation
- database foundation
- security baseline

## Phase 1 — Source & Artifact

- source registry
- acquisition interface
- raw artifact ledger
- hashing
- deduplication
- source health

## Phase 2 — Observation

- observation contract
- normalization
- extraction validation
- evidence boundary

## Phase 3 — Entity

- canonical entities
- aliases and identifiers
- conservative entity resolution

## Phase 4 — Event

- event extraction
- event lifecycle
- temporal event relationships

## Phase 5 — Temporal World State

- valid time
- observed time
- knowledge-as-of
- snapshots and historical reconstruction

Later phases add geospatial intelligence, relationships, change detection,
correlation/contradiction, signals, APIs, monitor UI, replay/backtesting, and
Tinlance ecosystem integrations.
