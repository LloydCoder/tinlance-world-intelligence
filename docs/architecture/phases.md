# Implementation phases
Phase 0 — Foundation: repository, contracts, ontology, CI, documentation, database, security.
Phase 1 — Source & Artifact: source registry, acquisition, raw artifacts, hashing, deduplication, source health.
Phase 2 — Observation: schema, normalization, validation, provenance, extraction contracts.
Phase 3 — Entity Intelligence: entity model, identifiers, aliases, resolution, merge/split, confidence.
Phase 4 — Event Intelligence: event ontology, extraction, correlation, lifecycle, provenance.
Phase 5 — Temporal World State: temporal assertions, historical state, snapshots, knowledge-as-of.
Phase 6 — Geospatial Intelligence: PostGIS, geometry, indexing, geofencing, proximity, spatial-temporal queries.
Phase 7 — Relationship Intelligence: ontology, temporal relationships, traversal, relationship change.
Phase 8 — Change Engine: before/after, classification, significance, source-vs-world-change.
Phase 9 — Correlation & Contradiction: cross-source correlation, independence, contradiction, corroboration.
Phase 10 — Signal Engine: rules, contracts, explanation, versioning, evaluation.
Phase 11 — Intelligence API: entity/event/world-state/change/signal/evidence/provenance/spatial-temporal queries.
Phase 12 — World Monitor: map, event stream, entity explorer, timeline, changes, signals, evidence, provenance.
Phase 13 — Replay & Backtesting: historical replay, deterministic pipelines, signal backtesting, regression fixtures.
Phase 14 — Advanced Intelligence: independence graph, temporal reasoning, anomalies, advanced spatial-temporal correlation, knowledge-as-of, cards, explanations.
Phase 15 — Tinlance Ecosystem: ReconOS, TADS, Agent OS, Agent Platform, external APIs, SDKs, governed capabilities.
