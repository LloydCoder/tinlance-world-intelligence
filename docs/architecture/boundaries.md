# Architecture Boundaries

## World Intelligence

Owns world-state semantics, provenance, temporal modeling, entity/event/relationship intelligence, changes, signals, and intelligence APIs.

## ReconOS

Owns governed acquisition/recon capabilities.

## TADS

Consumes intelligence for target and demand intelligence.

## Agent OS

Consumes controlled intelligence capabilities.

## Agent Platform

Owns policy, authorization, approval, execution, and runtime governance.

No layer should silently assume the authority of another.
