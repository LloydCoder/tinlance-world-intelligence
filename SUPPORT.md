## Questions and usage help

Use GitHub Issues for reproducible bugs, documentation gaps, and concrete feature proposals. Include:

- repository commit or release;
- Python version and operating system;
- relevant configuration with secrets removed;
- exact command or API request;
- expected result;
- actual result;
- relevant logs or traceback.

Do not post credentials, private source material, or sensitive production data.

## Security issues

Do not use a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## Feature requests

Explain the user problem, affected boundary, proposed outcome, and why the capability belongs in World Intelligence rather than ReconOS, TADS, Agent OS, or Agent Platform.
